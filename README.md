# pstack-hermes-build

This is a [Hermes](https://hermes-agent.nousresearch.com/) build of [pstack](https://github.com/cursor/plugins/tree/main/pstack) with personal customizations. It is generated by [scotu/pstack-hermes](https://github.com/scotu/pstack-hermes). Don't edit the `upstream` branch by hand.

- **`upstream`** is the exact output of `sync.py`, built from cursor/plugins. Its exact commit is recorded in `UPSTREAM`.
- **`main`** is `upstream` plus the changes listed in `CUSTOMIZATIONS.md`. Install this branch.

```
hermes -p <profile> plugins install https://github.com/scotu/pstack-hermes-build --enable
```
